# Contributing

PermanentUnderclass is a utility that I constantly change to suit specific
needs, including substantial changes to its direction and architecture. This
project is therefore not accepting external code contributions or pull requests
at this time.

Bug reports are welcome. Please describe the macOS and app versions, what you
expected, what happened, and the smallest reliable way to reproduce it. Remove
API keys, transcripts, reference material, recordings, and other private data
before attaching logs or screenshots.

Anyone is free to fork and modify the project for their own use under the MIT
License.

Security vulnerabilities should be reported privately as described in
[SECURITY.md](SECURITY.md), not in a public issue.
