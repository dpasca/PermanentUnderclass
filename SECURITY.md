# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability, leaked secret,
or privacy problem. Use GitHub's private vulnerability reporting feature for
this repository instead. If that feature is unavailable, contact the maintainer
through the email address on the maintainer's GitHub profile and include only
the minimum detail needed to establish a private channel.

Do not include real API keys, transcripts, recordings, reference documents, or
other private user data in the initial report. A useful report identifies the
affected revision, explains the impact, gives reproducible steps using synthetic
data, and suggests a mitigation when possible.

You should receive an acknowledgement within seven days. There is currently no
guaranteed remediation timeline or bug-bounty program.

## Supported versions

This project changes quickly and does not maintain long-lived release branches.
Security fixes target the latest code on `master`; older revisions are not
supported.
